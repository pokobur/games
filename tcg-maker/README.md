# 自作TCGカードメーカー (TCG Card Maker)

ブラウザ上（スマートフォン・PC）で動作する、本格トレーディングカードゲーム（TCG）風カードジェネレーターのWebアプリケーション（SPA）です。  
サーバーを一切使用せず、**画像合成・データ保存・PDF面付け出力までの全処理をクライアントサイド（ブラウザ内）で高速・完結**処理します。

---

## 🌟 主な特徴 & 実装機能

### 1. カード作成タブ（メインエディタ）
- **上下分割UI（モバイルファースト）**:
  - **画面上部（固定エリア）**: 高解像度Canvasプレビューを常時表示。下部フォームをスクロールしても常に仕上がりを確認可能。拡大・縮小表示の切り替えボタン付き。
  - **画面下部（スクロールフォーム）**: リアルタイム描画と連動した入力UI。
- **イラスト操作（直感的ジェスチャー）**:
  - ドラッグ（スワイプ）による位置移動（X, Y offset）。
  - ピンチイン/アウトおよびマウスホイールによる拡大縮小（0.5x〜2.5x）。
  - アップロード画像は自動でクリッピング枠に `object-fit: cover` フィット。
  - スライダーによる微調整、位置リセット、画像解除に対応。
- **TCG規格に準拠した4層描画（HTML5 Canvas API）**:
  - レギュラーサイズ（63mm × 88mm ≒ 1 : 1.397）を **756px × 1056px（12px/mm ≒ 305dpi）** の高解像度でレンダリング。
  - **Layer 1（背景）**: 属性テーマに基づくリッチなグラデーション＋地紋＋光彩。
  - **Layer 2（イラスト）**: イラスト枠矩形に `ctx.clip()` で切り抜き描画。
  - **Layer 3（フレーム）**: 金属光沢のカード枠・ネームバー・レベル帯・種族バー・効果欄・ステータスバッジ。
  - **Layer 4（テキスト・アイコン）**: 属性シンボル印章、カード名、レベル（星バッジ＋数値）、種族、効果テキスト、ATK/HP。
- **6属性のカラー & 金属調フレーム**:
  - **炎 (Fire)**: 深紅 / ゴールド (`#B71C1C`)
  - **水 (Water)**: 紺碧 / シルバー (`#0D47A1`)
  - **地 (Earth)**: アースブラウン / ブロンズ (`#4E342E`)
  - **風 (Wind)**: エメラルドグリーン / シルバー (`#1B5E20`)
  - **光 (Light)**: 白金色・ライトイエロー / ゴールド (`#FFF9C4` / `#FBC02D`)
  - **闇 (Dark)**: 紫紺・ダークグレー / メタリック (`#212121` / `#4A148C`)
- **入力制限 & テキスト自動折り返し**:
  - カード名: 全角最大12文字、長さに応じた自動フォントサイズ縮小。
  - レベル: 1〜10（★の連続描画 + レベル数値）。
  - 種族・タイプ: 全角最大8文字。
  - 効果テキスト: 全角最大80文字、最大5行。1行あたり約16文字で枠幅に合わせて自動折り返し（禁則処理・手動改行 `\n` 対応）。
  - ATK / HP: 半角数字4桁（0〜9999、全角入力の自動半角変換・数値クランプ）。
- **出力 & 保存**:
  - 高解像度 PNG ダウンロード。
  - IndexedDB への新規保存 / 上書き保存 / 複製保存。

### 2. コレクション（図鑑）タブ
- 作成したカードをグリッド表示で一覧確認。
- 属性別フィルターチップ（属性ごとの所持枚数バッジ付き）。
- カード名・種族によるインクリメンタル検索。
- 更新順、作成順、名前順、レベル順、ATK順、HP順でのソート。
- **詳細モーダル**:
  - 高解像度プレビューの閲覧。
  - ワンタップで編集画面へ呼び出し（新規編集または複製編集）。
  - ワンタップで選択中のデッキに追加。
  - 単体PNG保存 / 削除。
- **データ管理（バックアップ & 復元）**:
  - 全カードおよび全デッキのJSONエクスポート（画像はDataURL化して内包）。
  - JSONファイルからの安全な一括復元。

### 3. デッキ構築・印刷タブ
- **複数デッキ管理**: 新規作成、名前変更、削除、デッキ切り替え。
- **デッキ構築（最大40枚）**:
  - コレクションからワンタップでデッキに投入。
  - デッキ内リストでのステッパー（＋／−）による枚数調整。
  - 合計枚数カウンター、上限プログレスバー、属性別の投入枚数チップ表示。
- **印刷用PDF出力（`jsPDF` によるA4面付け）**:
  - A4サイズ（210mm × 297mm）に 3×3（計9枚）のカードを等倍配置。
  - 家庭用プリンター・コンビニプリントでの印刷に対応（100%等倍印刷でカードサイズ 63×88mm）。
  - **トンボ（裁断線）**: 切り出しを容易にするガイド線を自動描画。
  - **カード間隔調整**: 0mm〜3mm から選択可能。
  - **裏面ページの追加（両面印刷対応）**: 豪華なオリジナル裏面デザインを長辺とじ両面印刷用に**左右反転（ミラー配置）**して自動生成。

## 🛠 技術スタック

- **フロントエンド**: TypeScript, HTML5 Canvas API, CSS3 (Modern Responsive & Dark Theme)
- **ビルドツール**: Vite 6
- **データベース**: IndexedDB (`Dexie.js 4`)
- **PDF生成**: `jsPDF 4`（Code-SplittingによりPDF出力時のみ非同期ロード）
- **動作環境**: モダンブラウザ（iOS Safari / Android Chrome / macOS / Windows PC）

## 🚀 開発 & ビルド手順

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド（型チェック + Viteビルド）
npm run build

# ビルド結果のプレビュー
npm run preview
```
