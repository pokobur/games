プライバシーポリシー

ドキドキ！わなしかけすごろく（Web版 / Androidアプリ版：game.plyo.dokidokisugoroku）

1. 取得・保存する情報

本アプリでは、ゲームデータの保存・引き継ぎおよびアプリ内購入の処理のために以下の情報を取り扱います。

  • アカウント認証情報（Firebase Authentication）： ゲスト利用時の匿名ユーザー識別子（UID）、および Google アカウントまたはメールアドレス連携時に提供されるメールアドレス・表示名・UID。
  • ゲーム内ウォレット・購入履歴データ（Cloud Firestore）： 所持コイン数、カードのかけら数、解放済みステージ・わなカード・アバター・スキン・盤面テーマ、対戦アイテム所持数、ガチャ回数、注文履歴（商品ID・決済プロバイダ種別・注文状態・セッションID／注文ID等）、およびコイン増減台帳。
  • 端末内保存データ（localStorage）： 音量・自動ロール・CPU速度等のゲーム設定、参加プレイヤー名・アイコン設定、自作コースデータ、およびオフライン／同期補助用のウォレットキャッシュ。

2. 決済に関する情報の取り扱い

  • Webブラウザ版：決済代行会社（Stripe）のホスト型決済ページにて処理されます。クレジットカード番号等の機微な決済情報を当ゲームのサーバーで直接取得・保持することはありません。
  • Androidアプリ版（Google Play）：Google Play Billing（Digital Goods API / PaymentRequest および Google Play Developer API）を通じて処理されます。クレジットカード番号等の機微な決済情報を当ゲームのサーバーで保持することはありません。

3. 利用している外部サービス

  • Google Firebase（Authentication / Cloud Firestore / Cloud Functions）
  • Stripe（Webブラウザ版決済）
  • Google Play Billing / Google Play Developer API（Androidアプリ版決済および購入検証）
  • Google Fonts（Webフォント配信）

4. 利用目的

上記の情報は、ゲームの進行・設定・自作コースの保存、ログイン連携によるデータ引き継ぎ、ガチャおよびアプリ内アイテム・有料商品の付与・復元・不正決済防止（返金やチャージバックに伴う権限取り消しを含む）の目的で利用します。

6. アカウントとデータの削除について

アカウント連携をしている場合、運営者へのメール連絡により、アカウントと関連データの削除をリクエストできます。

  • 削除の手順：連携しているメールアドレスから、お問い合わせメールアドレス（find_info@plyo.blog）宛に、件名を「アカウント削除希望」としてご連絡ください。本人確認のうえ、原則として14日以内に削除いたします。
  • 削除されるデータ：Firebase Authentication のアカウント情報（メールアドレス・表示名・UID）、および Cloud Firestore に保存されたゲーム内ウォレット・購入履歴データ。
  • 保持されるデータ：法令上の義務の履行や不正決済への対応のため、注文履歴の一部を削除後も最長1年間保持する場合があります。その場合も、それらの目的以外には利用しません。
  • 端末内データ：端末内に保存されたデータ（ゲーム設定・自作コース等）は、ブラウザのサイトデータを削除することで、ご自身で削除できます。
